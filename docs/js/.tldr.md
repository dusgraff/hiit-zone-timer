# js

## Scope

The app's JavaScript, as ES modules loaded by `index.html` (no build step). Profile and workout data live here as modules (profiles.js, workouts.js).

## Contents

- [main.js](main.js) — entry point: shows the version, wires up menu, button click sound, Monitor, Select profile and workout screens, and router; app-wide reconnecting banner and return to Monitor on a lost connection.
- [bluetooth.js](bluetooth.js) — heart rate monitor connection (Web Bluetooth, BLE Heart Rate Service): connect, disconnect, one-attempt auto-reconnect, measurement parsing, battery; emits state/reading/battery events.
- [router.js](router.js) — hash-based screen switching (`#monitor`, `#profile`, `#select-workout`, `#workout`), screen guards (redirects), screenchange event; app always opens on Monitor.
- [menu.js](menu.js) — hamburger menu open/close behavior.
- [profiles.js](profiles.js) — fitness profile data (Sedentary/Average/Athletic zone minimums) and zone helpers: zone for a bpm, display ranges, zone labels.
- [session.js](session.js) — in-memory session state: the selected profile, with a profilechange event.
- [workouts.js](workouts.js) — workout data: the nine workouts (Demo, Moderate/Hard × 5–20 min), phase durations, mode zone targets, phase list builder.
- [workout-engine.js](workout-engine.js) — workout timer logic with no UI: HR-gated phase timers, statuses, climbing detection, below-target alarm rules and tuning constants.
- [workout-screen.js](workout-screen.js) — Select workout (guards, workout buttons) and Running workout screens: progress bar, timer display, end screen, wake lock, ending the workout on leaving.
- [sounds.js](sounds.js) — Web Audio cues and vibration: button click, phase change, below-target alarm, workout-complete fanfare.
- [profile-screen.js](profile-screen.js) — Select profile screen: profile buttons (active highlighted), zones view, Select workout button.
- [version.js](version.js) — app version constant shown in the title bar (major.two digits, e.g. 1.00; digits bumped per pushed change).
- [monitor.js](monitor.js) — Monitor screen UI: connect/disconnect, status, live heart rate and stats, current zone and active profile, Select profile button.
