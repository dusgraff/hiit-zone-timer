# docs

## Scope

The deployable web app: plain HTML/JS/CSS with no build step, served as-is by GitHub Pages, which deploys this folder from `main` (Pages only allows the repo root or `/docs`). Despite the name, this is the app, not documentation: specs live in `../specs/` and ADRs in `../specs-ADRs/`.

## Contents

- [CLAUDE.md](CLAUDE.md) — rules for editing the app: bump the version in js/version.js with every pushed change.
- [index.html](index.html) — the app's single page: title bar with version and hamburger menu, reconnecting banner, and all screens as sections (Monitor, Select profile, Select workout, Running workout).
- [css/](css/.tldr.md) — app stylesheet.
- [js/](js/.tldr.md) — app JavaScript as ES modules: entry point, Bluetooth connection, router, menu, screens, profile and workout data, workout timer engine, sounds, session state, version.
- [prototype-hr-connect.html](prototype-hr-connect.html) — standalone prototype: connect button, Bluetooth device picker, live heart rate display (standard BLE Heart Rate Service). For verifying the Polar strap works before real app work.
