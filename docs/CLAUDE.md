# App folder rules

- **Bump the version.** Any change to the app's files in this folder that will be pushed increments the two-digit number in [js/version.js](js/version.js) (`0.04` → `0.05`). Bump once per batch of changes, not per file. See [specs/app-architecture.md](../specs/app-architecture.md#screens-and-menu).
